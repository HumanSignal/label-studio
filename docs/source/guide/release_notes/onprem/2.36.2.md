## Label Studio Enterprise 2.36.2

<div class="onprem-highlight">Fixed support report OOM/inaccuracies on large activity logs; patched anyio security vulnerabilities</div>

*Sep 21, 2026*

Helm Chart version: [2.0.8](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### Security

- Fixed vulnerabilities in a bundled dependency that could allow TLS certificate spoofing or cause background worker processes to hang indefinitely ([CVE-2026-63374](https://github.com/advisories/GHSA-82r6-8w77-94w6), [CVE-2026-64847](https://github.com/advisories/GHSA-5p39-cfhj-2xmp)).

### Bug fixes

- Fixed an issue where generating a support report on instances with large activity logs could exhaust worker memory and fail. This also corrected inaccurate session counts and concurrent session totals that could appear in generated reports.
