## Label Studio Enterprise 2.36.0

<div class="onprem-highlight">Bulk Data Manager column edits, Custom Interfaces sandbox, and improved member analytics.</div>

*Aug 20, 2026*

Helm Chart version: [2.0.7](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

#### Add or update task data columns in bulk

The **Add or Update Columns** Data Manager action is now available in the Data Manager. Add new fields to your task data or update existing values across many tasks at once, without re-importing your dataset.

For more information, see [Use the Data Manager](manage_data).

![Screenshot](/images/releases/2-36-add-or-update-columns.png)

#### Host the Custom Interfaces sandbox on your own domain

On-premises deployments can now host the Custom Interfaces sandbox on the same domain as Label Studio. Browser features that require a real origin, such as camera and microphone access, now work inside a Custom Interface.

For more information, see [Interfaces](interfaces).

#### A vertical layout for the Annotations panel

Reviewers can switch to a new [vertical Annotations panel layout](https://humansignal.com/changelog/#2026-07-21-vertical-annotations-sidebar), with filtering support, to compare annotations for a task without leaving Quick View.

![Screenshot](/images/releases/2-36-vertical-annotation-sidebar.png)

#### Additional new features

- Member Management now has an "Assign same-level roles" permission, letting you control whether Managers and Admins can invite or promote users to their own role level. For more information, see [Customize organization permissions](admin_permissions).
- Managers and above can lock a Data Manager tab to prevent other users from changing its filters, columns, or view settings.
- Grid view in the Data Manager supports selecting every displayed or filtered task at once, and right-click context menus are now available throughout the Data Manager and on the Organization/Project Members tables.
- The Analytics KPI APIs have been updated and documented for use with the SDK.
- Interface and template descriptions now render Markdown, including bold text, lists, inline code, and links.

### Feature updates

#### Improvements to Data Manager filters

A number of enhancments have been made to Data Manager filters, allowing for more precise filtering of tasks:

- New filters for annotation results, so you can see which tasks contain specific annotation labels. You can add multiple child filter lines and combine them with AND/OR logic.
- Data Manager filters on Annotators, Reviewers, Comment authors, and similar user columns now support selecting multiple users.

![Screenshot](/images/releases/2-36-improved-dm-filters.png) 

#### Member Performance for larger teams

Analytics > Member Performance now handles bigger workforces: filter members by project or workspace, select every member at once, and report on up to 1,000 members. Tables are sortable and hide members with no activity.

For more information, see [Members dashboard](dashboard_members).

### Security

We continued hardening the platform behind the scenes: dependency security updates, bug fixes, and reliability improvements.

### Bug fixes

- Fixed project-level role overrides (for example, an org-level Annotator upgraded to Reviewer on a specific project) not being respected on Quick View deep links.
- Fixed tasks incorrectly staying marked as Done/Reviewed after being edited following a review; such tasks now correctly return to the review queue.
- Fixed the review stream sometimes serving the same task to multiple reviewers, and manually assigned review tasks not reaching the correct reviewer.
- Fixed Data Manager annotation counters drifting out of sync after bulk delete, bulk create, or cloud storage sync operations.
- Fixed duplicate user entries appearing in a project's member list, and the Data Manager not refreshing automatically after deleting tasks in some cases.
- Fixed a bug allowing annotators to submit multiple annotations for the same task by clicking submit while it was still loading, and fixed duplicate draft creation and orphaned draft resurrection that could lead to duplicate annotations.
- Fixed the Rejected badge rendering incorrectly in Quick View for Interface projects, and review Accept/Reject buttons not appearing when the PII firewall was enabled.
- Fixed several Video Vector and SAM2-assisted tracking issues, including regions failing to close, labels not updating from the canvas dropdown, frame navigation getting stuck or not blocked appropriately while drawing, and regions disappearing at the start/end of a tracked range or after using "Track Both."
- Fixed issues in system Interface templates (PDF OCR, LiDAR Object Detection, Document AI, Wearable Activity, Robotics Episode Review), including region visibility, hiding, and locking, zoom and page navigation, relation display, editable transcription fields, and missing outliner action buttons.
