## Label Studio Enterprise 2.36.0

<div class="onprem-highlight">Added View-Only org members, major Payments hub upgrades, mobile-responsive navigation, and contributor project opt-in</div>

*Aug 18, 2026*

Helm Chart version: [2.0.7](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

- Added a View-Only organization member type with read-only access to Analytics and assigned project dashboards, including invite, upgrade, and SCIM/SAML provisioning support.
- Contributors can now discover and self-join projects that admins have opened for contributor opt-in, based on configurable eligibility requirements; once removed from a project they self-joined, they cannot rejoin it themselves (a manager can still add them back).
- Added an "Assign same-level roles" permission under Member Management, controlling whether Managers and Admins can invite or promote users to their own role level.
- Data Manager tabs can now be locked by managers and above to prevent other users from changing tab configuration.
- Finalized and released the "Add or Update Columns" Data Manager action for adding or updating task data columns in bulk.
- Data Manager grid view now supports selecting all displayed or filtered tasks at once, and right-click context menus are now available in the Data Manager and on Organization/Project Members tables.
- Members and Project Members tables can now be exported to CSV.
- Workforce Discord channel integrations now support more than 500 members per channel.
- Added a configurable annotator evaluation metric (ground truth agreement, acceptance score, or rejection rate) for pausing underperforming annotators, with evaluation status shown on the project dashboard.
- Analytics → Member Performance now supports larger teams: filtering members by project/workspace, a true "select all," reporting for up to 1,000 members, and sortable tables that hide members with no activity.
- The Analytics KPI APIs are now public and documented for use with the SDK.
- Added a DocLang (.dclx) export format for Docling Interface projects, including referenced document images.
- Added Markdown rendering (bold, lists, inline code, links) for Interface and template descriptions.
- On-premises deployments can now host the Custom Interfaces sandbox on the same domain, enabling camera, microphone, and other features that require a real browser origin.
- Added a new vertical Annotations panel layout option for reviewers, with filtering support.
- Added YouTube video embedding support in Courses, and Courses now show editor presence and lock pages currently being edited to prevent authors from overwriting each other's changes.
- Added a confirmation email sent to workforce contributors once they complete onboarding.
- The application's top navigation, home page, workforce home page, and account settings pages are now responsive on mobile devices, with a redesigned mobile navigation menu.

### Feature updates

- Added an average and median time-per-item column to payment batch reports, and a total dollar amount across all batches in the bulk pay-run drawer and pay runs list.
- Project links in the Program Overview pending breakdown are now clickable.
- Restricted the Payments hub and pay configuration (program and project level) to admins and owners.
- Added the ability to override country tags, missing pay rates, and hours/average time directly on a project's payment batch, in addition to the program level.
- Pay runs now show a breakdown of which projects generated with warnings and why, and a per-milestone breakdown of paid vs. total vs. not-met annotations and reviews.
- Renamed the "New" column on Payments > Projects to "Pending" with separate annotation/review counts, and renamed "Pending" to "Need to pay" on the Programs list to include in-draft batch amounts.
- The Payment Status filter in the Data Manager is now a dropdown of valid values instead of free text.
- Added Export CSV for pay rates on program and project settings pages, matching the existing Import CSV format, and a "Remove all rates" action to bulk-delete annotator or reviewer rates.
- Added an option to exclude ground truth annotations from payment, and to exclude annotators and/or reviewers from payment at the project level.
- Project payments now show a separate bucket for items excluded due to internal-user annotations.
- Added timezone-aligned accounting exports so month-end totals reconcile with external payment providers.
- You can now select a payment program when creating a project, and duplicating a project now preserves its associated payment program and pay configuration.
- Redesigned Payments settings pages with a clearer layout, autosaving configuration, role-scoped controls, and standardized tables; approving a pay run is now blocked if configuration changed after batch generation, and a warning now appears when closing an edited pay run without saving.
- Added per-worker risk indicators (quality, pace, idle time) to payment batch reports and the Payments Users page to help identify problematic patterns before approving pay.
- Added the ability to archive a payment program, and a "Last paid date" column to the Payments Programs list.
- Improved performance of the Payments Programs summary page.
- Data Manager filters on Annotators, Reviewers, Comment authors, and similar user columns now support selecting multiple users.
- Dimension-based result filters in the Data Manager now support cardinality-aware controls (single- vs. multi-select) and multiple child filter lines with AND/OR logic, and label distribution now supports nested ReactCode output fields as dimensions.
- Improved performance of the Dashboard, Members, and Data Manager pages on very large projects.
- Removed outdated "Agreement V2" wording from empty-state messages, applied consistent title casing to dashboard tabs, and removed unused columns from the Review Summary table.
- Improved the Throughput dashboard with updated KPI cards, a "Done" series in the Tasks by State chart, and percentage breakdowns in chart tooltips.
- Members dashboard tables now scroll within the table body instead of the whole page, with pagination remaining visible.
- Improved performance and reliability of streaming large audio files in Custom Interfaces.
- Course pages with multiple videos no longer preload and re-buffer all videos at once; course page names are now edited from the page settings panel instead of the sidebar.
- Improved the reliability of the AI-assisted Interface builder, including reduced token usage and better error recovery.

### Security

- Fixed an issue where quiz answers could be exposed to learners through the Courses API.
- Improved the annotator/reviewer PII firewall to anonymize user data on the server for stronger protection when the firewall is enabled.
- Fixed Data Manager comment and label filters returning results based on other users' annotations when applied by an annotator, which could expose information outside their own work.
- SAML SSO now requires signed assertions or responses by default.

### Bug fixes

- Fixed project-level role overrides (for example, an org-level Annotator upgraded to Reviewer on a specific project) not being respected on Quick View deep links.
- Fixed Reviewer-role users mapped to a project not seeing "Review All Tasks" in the Data Manager, or seeing "No work to review" on the homepage when the project used an automatic review queue.

- Fixed the on-premises Service Account limit being enforced per organization instead of environment-wide, a 500 error when using a deleted Service Account's access token (now returns 401), and unclear validation messages for over-length Service Account names.
- Fixed the "Learn more" link on the Service Accounts page pointing to a missing help page.
- Fixed the Throughput dashboard showing "Unable to load throughput data" for projects that exist only in a personal sandbox workspace, and sometimes showing zero annotating time despite logged work.
- Fixed exported CSV files from the Throughput dashboard missing the header for the first column.
- Fixed several Members dashboard issues: misleading "no annotators" messages when all participants are deselected, missing annotators with zero annotations in the participants dropdown, mismatches between the dropdown and the members table, and CSV export only including loaded rows instead of the full list.
- Fixed deleted or reviewer users displaying incorrect names, emails, or IDs in the Members dropdown, and "Fix + Accepted" annotations being incorrectly counted as "Accepted" in Member summaries.
- Fixed the Members dashboard hanging indefinitely on projects without a workspace, and the Members settings page showing paused users who are no longer part of the project.
- Fixed tasks incorrectly staying marked as Done/Reviewed after being edited following a review; such tasks now correctly return to the review queue.
- Fixed the Workforce homepage showing a "Start" (label) button instead of "Review" for users assigned as reviewer on a specific project, and annotators paused for failing evaluation can now access and correct their own rejected annotations.
- Fixed the review stream sometimes serving the same task to multiple reviewers, and manually assigned review tasks not reaching the correct reviewer.
- Fixed Data Manager annotation counters drifting out of sync after bulk delete, bulk create, or cloud storage sync operations.
- Fixed duplicate user entries appearing in a project's member list, and the Data Manager not refreshing automatically after deleting tasks in some cases.
- Fixed the Publish/Unpublish project modal reloading the project or closing/confirming unexpectedly, and a crash when navigating to project settings after browsing projects.
- Fixed several Data Manager filter issues: switching between filter columns causing a runtime error, incorrect results when combining "is not" with dimension and child filters, differences between pinned and unpinned filter panels, and long multi-select filter values overflowing their container.
- Fixed copying Data Manager cell contents showing "[object Object]" instead of the actual value, and a data-integrity issue where certain special characters could prevent saving an annotation.
- Fixed incorrect typing of task annotations returned by the SDK for role-based task endpoints.
- Fixed a bug allowing annotators to submit multiple annotations for the same task by clicking submit while it was still loading, and fixed duplicate draft creation and orphaned draft resurrection that could lead to duplicate annotations.
- Fixed accepting an annotation from an outdated Annotation History item discarding the reviewer's changes, and the draft-saving indicator getting stuck after selecting a history item.
- Fixed annotations losing regions when using Duplicate Annotation after accepting a model-generated region.
- Fixed the Rejected badge rendering incorrectly in Quick View for Interface projects, and review Accept/Reject buttons not appearing when the PII firewall was enabled.
- Fixed several Video Vector and SAM2-assisted tracking issues, including regions failing to close, labels not updating from the canvas dropdown, frame navigation getting stuck or not blocked appropriately while drawing, and regions disappearing at the start/end of a tracked range or after using "Track Both."
- Fixed the vertical annotations list not being scrollable, and filters (Accepted/Rejected/Fix + Accepted) not working correctly in that panel.
- Fixed numerous issues in system Interface templates (PDF OCR, LiDAR Object Detection, Document AI, Wearable Activity, Robotics Episode Review), including region visibility, hiding, and locking, zoom and page navigation, relation display, editable transcription fields, and missing outliner action buttons.
- Fixed the "Create a new annotation" button sometimes requiring two clicks, stale regions showing when switching between annotations, and a missing delete confirmation modal in Custom Interfaces.
- Fixed the Payments activity list showing the batch processing date instead of the actual work period, member tags rendering incorrectly in pay rate lists, and duplicating a project not preserving its inherited program rate settings.
- Fixed pay-run batch report pagination disappearing after a batch was regenerated, batch worker rows showing "Ready" instead of "Approved" after a pay run was approved, and the Payments Programs "Pending" estimate incorrectly counting work that was not yet eligible for payment.
- Fixed an issue where an annotation that was accepted and later rejected could still be paid.
- Fixed the payment program dropdown on the Duplicate Project modal only showing "No Program," the project filter not working on the Payments Overview page, and validation errors for the Budget field not being clear (including preventing negative budgets).
- Fixed Analytics → Member Performance data unexpectedly refreshing when saving a view, and truncated dimension names in Label Distribution not showing the full name on hover.
