## Label Studio Enterprise 2.35.0

<div class="onprem-highlight">Added Custom Interfaces with an AI builder, Service Accounts, Segment Anything, and revamped dashboards</div>

*Jul 29, 2026*

Helm Chart version: [2.0.7](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

- Added Custom Interfaces: build custom labeling UIs with an AI assistant, use built-in templates for common tasks (document review, OCR, ranking, keypoints, and more), and embed them in your own applications.
- Added Service Accounts: create non-human, API-only principals for integrations and automations that do not consume paid seats and can be blocked from browser-based login.
- Added interactive segmentation support (Segment Anything) for images and video, allowing regions to be generated from a connected ML backend.
- Added a custom color picker and additional preset colors for projects and workspaces.
- Reorganized Organization navigation into Members, Security, Settings, and Usage & License sections for clearer navigation.
- You can now bulk-assign existing organization members to workspaces or projects, including when all members are selected.
- Added "is any of" and "is none of" filter operators in Data Manager for filtering by a list of values.
- Added a randomize attribute for the Choices tag to reduce annotator position bias by shuffling option order per task.
- Added per-dimension agreement breakdown to task exports when Agreement V2 dimensions are enabled, and to the task summary view.
- Added support for bulk accepting or rejecting annotations directly from Data Manager.
- Organizations can now configure a custom Support link shown throughout the app.
- The Python SDK now supports the X-API-Key header for deployments with an additional authentication layer in front of Label Studio.
- Added review routing rules for Enterprise projects, allowing tasks to be routed to review based on agreement thresholds or a configurable sampling percentage.
- Added new Project Dashboard sections for Throughput, Data Quality, and Members performance, including velocity charts, label distribution, and agreement matrices.

### Feature updates

- Refreshed icons across Home, Projects, Data Manager, Organization, and the labeling editor for a more consistent visual style.
- Improved dark mode support across many pages, including project templates, the labeling editor toolbar, Organization settings, and Interfaces.
- Data export filenames now use the custom snapshot name you provide instead of a generic name.
- Improved performance of Data Manager filtering, sorting, and task list queries, and of agreement, project count, and review queue calculations, reducing timeouts on large projects.
- Restored single-frame stepping for the video timeline and fixed brush eraser rendering when regions overlap.
- Improved accuracy of agreement calculations for rectangles drawn with the three-point method, TimeSeries and Timeline labels, and per-region dimensions linked to multiple control tags.
- Unified the billing page URL across all plans and added a redirect from the old billing URL.
- Added an indicator on Data Manager agreement columns showing when agreement calculation settings differ from the defaults.

### Security

- Added protections against server-side request forgery (SSRF) for webhook URLs and S3 custom endpoints, blocking requests to local or private network addresses.
- Enforced authorization checks so users with the Manager role can only view or edit webhook and S3 storage configurations for projects they belong to.
- Fixed an issue where email addresses that differed only by capitalization could create duplicate accounts through SAML or SCIM provisioning.
- Restricted personal access token authentication for SCIM so it can only be used against SCIM provisioning endpoints, not general API endpoints.
- Fixed an issue where a project's custom script could be set even when custom scripts (Plugins) were disabled for the organization.

### Bug fixes

- Fixed several issues where annotation drafts could lose labeled regions, comments, or history after changing choices, navigating tasks, or reloading the page.
- Fixed a race condition that could create a "fake" draft when reviewers navigated between annotations in the review stream.
- Fixed onboarding evaluation tasks being blocked by overlap settings, which had prevented new annotators from receiving ground truth tasks.
- Fixed YOLO export with images when using local storage, and corrected category ID mapping in COCO exports.
- Fixed avatar overflow in Data Manager annotator/reviewer columns, missing tooltips for truncated saved view names, and crashes on saved views referencing stale agreement filters.
- Fixed several review workflow issues, including incorrect review counters, review sampling not applying correctly for older agreement configurations, and role filters resetting after removing a project member.
- Fixed agreement calculation issues, including NaN values in the agreement breakdown popover and incorrect agreement for conditional or per-region dimensions.
- Fixed SCIM reactivation of soft-deleted organization members so membership is correctly restored.
- Fixed activity log and saved analytics view filters not retaining the previously selected user or filter values after navigation.
- Fixed several stability issues in the labeling editor, including errors when switching tasks or annotations quickly and a race condition that could cause annotation deletion to fail.
- Fixed numerous issues in Custom Interfaces, including annotation submission validation, draft autosave reliability, comment and history synchronization, dark mode styling, rendering of region relations, and navigation in label and review streams.
