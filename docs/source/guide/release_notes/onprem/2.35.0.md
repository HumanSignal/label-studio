## Label Studio Enterprise 2.35.0

<div class="onprem-highlight">Custom Interfaces with AI, Service Accounts, redesigned Organization settings, and key security fixes</div>

*Jul 13, 2026*

Helm Chart version: [2.0.6](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

- Introduced Custom Interfaces: build fully custom labeling and review interfaces with an AI assistant, including chat-based iteration, templates, versioning, and live preview, alongside the traditional labeling configuration editor.
- Added Segment Anything Model (SAM2) support for interactive image and video segmentation, letting annotators generate regions from a click or bounding box and track them across video frames.
- Added Service Accounts: non-human, API-only user accounts for automations and integrations that are excluded from billing seat counts and blocked from browser-based session login.
- Redesigned the Organization navigation into four sections — Members, Usage & License, Security, and Settings — to make administrative settings easier to find.
- Added a Course Builder to project instructions, letting you create training courses with quizzes for annotators and reviewers, gate a project on course completion, and export course completion records.
- Added new Project Dashboard views for Throughput, Data Quality (agreement analysis and label distribution), and Member performance, including an inter-rater reliability matrix.
- Added "is any of" and "is none of" filter operators in Data Manager to filter by a list of values.
- Added a `randomize` attribute for the Choices tag to shuffle option order per task and reduce annotator position bias.
- Added a custom color picker and additional color swatches for projects and workspaces.
- Added the ability to bulk assign existing organization members to workspaces and projects, including when all members are selected.
- Added the ability to bulk accept or reject annotations from Data Manager.
- Added per-dimension agreement scores to task exports.
- Exported files now use the custom snapshot name you provide instead of a generic filename.
- Added the ability to customize the organization's support link shown in the application menu.
- Added self-service resending of expired email verification links.
- Added a `beforeSaveDraft` event for custom script plugins so annotation data can be processed (for example, encrypted) before drafts are saved.
- The SDK now supports authenticating with an X-API-Key header in addition to Authorization, and CLI type signatures were made easier to read.

### Feature updates

- Improved the accuracy and performance of Agreement V2 (dimension-based agreement), including filtering and sorting by agreement in Data Manager, IoU calculation for three-point drawn rectangles, TimeSeriesLabels agreement, handling of conditional/visibility-based controls, and NaN/consensus edge cases.
- Improved the Members and Data Quality dashboards, including links from counts to filtered Data Manager views, dimension-aware performance tables, and clearer indicators when agreement column settings are customized.
- Reduced the default ReactCode iframe permissions to four essential values (camera, fullscreen, geolocation, microphone) and clarified how to request additional permissions.
- Improved audio decoding reliability and performance with a new streaming and seeking decoder.
- Restored single-frame stepping in the video timeline and fixed several Video Vector and SAM2 drawing issues, including point placement, closing regions, adjusting points, and maximum point limits.
- Improved brush tool rendering so overlapping strokes and erasers no longer visually bleed into neighboring regions.
- Long-running Data Manager bulk annotation deletions are now processed asynchronously to avoid request timeouts.
- Annotation time is now credited only when an annotation is submitted, updated, or saved as a draft, instead of accumulating during passive viewing.

### Security

- Fixed authorization checks so that users with the Manager role can no longer view or modify webhook and S3 storage configurations for projects they are not a member of.
- Added validation to block webhook and S3 storage endpoint URLs that resolve to internal or private network addresses, helping to prevent server-side request forgery.
- Fixed duplicate user accounts being created when SAML/SCIM identity providers sent the same email address with different capitalization.
- Fixed SCIM authentication so that Personal Access Tokens are accepted for SCIM provisioning, and restricted Personal Access Token authentication to SCIM endpoints only.
- Added validation to prevent enabling custom scripts (plugins) on a project when plugins are disabled for the organization.
- Added protections to prevent search engines from indexing organization invite, signup, and authentication pages.
- Fixed several API endpoints that could return server errors instead of a validation error when given malformed input, such as overly long import URLs, malformed filter values, and invalid project ID lists.

### Bug fixes

- Fixed several issues that could cause annotation drafts, comments, or annotation history to be lost or not saved when navigating between tasks, switching annotations, or using the review and label streams, particularly in projects using Custom Interfaces.
- Fixed onboarding evaluation tasks being blocked by overlap settings so new annotators can access ground truth tasks as expected.
- Fixed COCO export not respecting explicit category IDs defined in the labeling configuration.
- Fixed YOLO export with images producing an empty images folder when using local storage.
- Fixed the prediction score showing as empty in Data Manager when the model name differs from the model version.
- Fixed cloud storage sync imports failing when imported annotations included exported user objects or a unique identifier field.
- Fixed PDF files failing to load in Quick View and Label Stream.
- Fixed avatars in Data Manager overflowing into neighboring table cells.
- Fixed deleting reviews for a specific reviewer from also deleting reviews left by other reviewers.
- Fixed a timeout error that could occur when retrieving a task with a large number of annotations.
- Fixed the Usage & License tab missing from the Organization navigation for Admin users.
- Fixed the Publish project modal reloading the entire project when opened.
- Fixed project-level role overrides not being respected when opening Quick View through a deep link.
- Fixed SAML service provider URLs rendering with http instead of https when Label Studio is deployed behind a TLS-terminating proxy.
- Fixed a server error that could occur when resolving task media if the authentication check failed.
- Fixed several Data Manager issues, including saved views crashing after Agreement V2 was disabled, filters becoming duplicated, and role and filter selections resetting unexpectedly on the Members page.
