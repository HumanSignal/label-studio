## Label Studio Enterprise 2.35.0

<div class="onprem-highlight">Custom Interfaces, VideoVector autotracking with SAM2, agreement-based review sampling, and bulk review from the Data Manager</div>

*Jul 29, 2026*

Helm Chart version: [2.0.7](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

#### Custom Interfaces: build labeling and evaluation interfaces without XML

You can now design labeling and evaluation interfaces across additional data modalities by describing the layout, controls, and outputs you want in plain language, rather than writing XML.

**Availability:** Custom Interfaces ships behind a feature flag in 2.35. Contact your HumanSignal account team to turn it on for your workspace.

### Feature updates

#### Video labeling: VideoVector with SAM2 autotracking

- You can now draw `VideoVector` regions and autotrack them across frames using the SAM2 integration.

#### Review, agreement, and Data Manager

- Sample the review queue based on inter-annotator agreement.
- Accept or reject annotations in bulk from the Data Manager, with searchable user dropdowns.

#### Dashboards and analytics

- The project **Members** page now lives under **Dashboard**.

#### Platform and reliability

- Shipped dependency security updates, Sentry auto-fixes, and CI reliability improvements.

### Bug fixes

- Fixed value-counts aggregation performance for agreement and analytics queries.
- Corrected date-range accuracy in member performance queries.
