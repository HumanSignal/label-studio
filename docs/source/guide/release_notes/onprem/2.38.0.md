## Label Studio Enterprise 2.38.0

<div class="onprem-highlight">Filter tasks by review details, create projects from selected tasks, and a broad security hardening pass</div>

*Nov 12, 2026*

Helm Chart version: [2.0.13](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### New features

#### Filter tasks by review details

The Data Manager Filters panel has a new **Reviews** section. Combine reviewer, review date, review result, and whether a review is the current verdict in one filter, and Label Studio returns the tasks with a single review that meets every condition.

For example, you can find the tasks a specific reviewer rejected last week, without also matching tasks where one reviewer rejected and a different reviewer reviewed last week.

The Reviews section is available to Managers, Administrators, and Owners.

#### Create a project from selected tasks

Use the new **Create Project From Tasks** Data Manager action to copy selected tasks into a new project. The new project copies the source project's settings and lands in the same workspace.

- Choose whether to copy the tasks' annotations along with the task data.
- Optionally remove the copied tasks from the source project. Label Studio removes them only after a backup export of exactly those tasks completes.
- Reviews, comments, drafts, and predictions are not copied.

### Security

This release closes a set of server-side request forgery, cross-organization access, and cross-site scripting issues.

!!! note "Project instructions now escape HTML"
    Project instructions now escape unsafe HTML by default. If your projects rely on custom HTML in their instructions, the organization owner can turn it back on.

- Fixed several server-side request forgery (SSRF) vulnerabilities that could cause the server to make requests to internal or arbitrary network addresses, including SAML single sign-on metadata fetching, S3/Azure/GCS/Databricks cloud storage configuration, export media downloads, and the task source file proxy.
- Fixed a stored cross-site scripting vulnerability in project instructions; unsafe HTML is now escaped by default and can only be re-enabled by the organization owner.
- Fixed a vulnerability allowing SAML single sign-on authentication to be processed using an attacker-controlled hostname instead of the deployment's configured host.
- Fixed several API endpoints that could expose or modify data belonging to another organization due to missing tenant or permission checks, including projects, tasks, annotations, comments, prompts, dataset storage, and SAML/SCIM configuration.
- Fixed a vulnerability where creating a storage connection could copy another organization's stored cloud credentials.
- Fixed a vulnerability that could allow account takeover through unrestricted organization membership and password-change endpoints.
- Uploaded HTML, SVG, and XML files are now served in a sandboxed context to prevent them from executing as part of the application.
- Fixed the data directory's configuration file (containing the application's secret key) being created with overly permissive file access.
- Organization invite links now expire automatically instead of remaining valid indefinitely.
- Fixed organization agreement and project terms pages rendering unsanitized HTML and an unvalidated redirect after accepting an agreement.
- Fixed several endpoints that returned generic server errors instead of proper permission or validation errors, and closed signup paths (including social login) that could bypass organization email domain validation and verification requirements.
- Updated several third-party dependencies to address known vulnerabilities.

### Bug fixes

#### Interfaces

!!! attention Availability
    Interfaces is in beta and available on request. Self-hosted deployments are limited to the local development option.

- Fixed several Custom Interface editor issues, including dark mode styling for date/time pickers and numeric inputs, labels editor alignment, undo/redo completing in a single action, selecting regions from the Regions panel, correct lock icons and edit prevention on locked regions, and comment indicator icons on regions.
- Fixed brush, bitmask, and vector/polyline region drawing and point editing in Custom Interfaces so strokes are continuous, multiple regions do not overwrite each other, and mask colors match label colors.
- Fixed several draft-saving and reload issues in Custom Interface Quick View and Label Stream, including slow audio reloads after submit, missing "Draft saved" confirmations, unnecessary task reloads, and the Submit button staying disabled after Undo.
- Fixed permission checks for creating, duplicating, and saving interfaces and for creating projects from interfaces, so users without the required permission are blocked with a clear message.
- Fixed local interface development workflow issues, including missing sample data and output schema definitions, slow audio preview rendering, outdated cached builds after a deployment, and local file changes sometimes not being picked up.
- Fixed dimension and agreement filters not matching correctly for Custom Interface projects, and improved the performance of the filtered Label Distribution report.

#### Labeling and Data Manager

- Fixed the v1 embed view rendering the full application interface instead of the labeling editor, and corrected permission scoping for embedded data requests.
- Fixed text (NER) span regions that could not be resized in recent browser versions, and fixed locked NER regions being resizable when they should not be.
- Fixed multi-page image tasks showing a blank page after the first one when multiple pages share the same image URL.
- Fixed Data Manager tab titles changing font size after opening Quick View, and fixed the "Order by" toolbar control rendering as two separate buttons instead of one combined control.
- Fixed annotators being unable to load tasks in the Data Manager on projects with very large labeling configurations.
- Fixed task activity tracking failing when navigating between tasks with an unsaved draft.
- Fixed the Cache Labels Data Manager action returning blank results for BrushLabels and failing on very large projects.
- Fixed export snapshot files remaining in storage after the export snapshot itself was deleted.
- Fixed an invalid OpenAPI schema export that could not be imported into API gateway tools.

#### Reviews

- Fixed several review-routing issues so rejected work that should return to the same annotator no longer gets lost if the project's allowed reject options change afterward, and historical rejections are classified correctly.
- Fixed the reviewer progress counter to again reflect the reviewer's own share of review work.
- Fixed a race condition that let two reviewers submit a review for the same task at the same time, and fixed the Accept button remaining clickable after a review was already submitted, which could record duplicate review actions.
- Fixed several issues with the "By Annotator" review task ordering, including tasks being served out of order, skipped, or stuck after tasks or reviews were deleted.

#### Members and Analytics

- Fixed the Membership dropdown panel extending beyond the members table and overlapping other content while scrolling, and fixed it truncating the additional-project count for members with long project names.
- Fixed the Tags filter on the Project Members page ignoring the "Any of / All of / None of" operator.
- Fixed bulk actions on Members pages (assign to workspace or project, tag members, remove from project) ignoring the filters currently applied to the table.
- Fixed the Add Members dialog showing an infinite loading state and an error in the Membership column for Managers.
- Fixed slow performance when selecting all members on the Analytics Member Performance page for large organizations.
- Fixed evaluation results and reviews from members who were removed from a project not appearing for view-only users and in totals, and fixed Administrators missing from the Member Performance user filter when a project was selected.
- Fixed view-only users being unable to save views on the Analytics Overview and Member Performance pages.

#### Single sign-on and SCIM

- Fixed validation and provisioning for single sign-on group mappings, including View-Only seat conflicts and workspace/project scoping for SCIM-provisioned view-only users.
- Fixed the "Assign same-level roles" permission being unavailable for Managers on on-premises deployments.
- Fixed SCIM-provisioned users losing their project memberships on first single sign-on login when manual project member management is disabled, and fixed SCIM provisioning failing once an organization reached its license seat limit.
