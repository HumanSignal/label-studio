## Label Studio Enterprise 2.37.0

<div class="onprem-highlight">Data Collection projects, Flex and View-Only seats, configurable reviewer rejections, and a mobile-friendly workforce experience.</div>

*Oct 09, 2026*

Helm Chart version: [2.0.11](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### Breaking changes

#### Payment programs replace per-project pay runs

Payment programs are now the only way to generate and approve payments. Per-project payment batch generation and the standalone **Payments > Projects** list have been removed, and existing pay runs move to the program level.

Review your payment programs before upgrading. Any workflow that generated batches from an individual project needs to move to a program-level pay run.

#### The project payments toggle is now a kill switch

Turning off **Enable payments** on a project stops payment for all work in that project until you turn it back on. Completed work is not lost: it pays out once you re-enable payments.

### New features

#### Data Collection projects

A new project type for crowdsourced file submissions. Contributors upload files from their phone or desktop, and you review and pay for the results in the same place you handle annotation work.

- Collect multi-file bundles in a single task.
- Set validation rules for file type, size, duration, resolution, and orientation.
- Review submissions and pay contributors through your existing review and payment setup.
- Contributors get in-card previews for images, video, and PDFs while they upload.

For more information, see [the docs](TODO-LINK).

#### Flex seats and View-Only seats

Two new seat types give you more control over how licenses are assigned.

- **Flex seats** let you assign working roles with claim-based capacity enforcement. Provision them through invites, SSO, or SCIM, and manage them from the Members page.
- **View-Only seats** give read-only access with limited navigation and a persistent status indicator. A View-Only member can be upgraded to a full seat at any time.

For more information, see [the docs](TODO-LINK).

![Screenshot](/images/releases/2-37-seat-types-members.png)

#### Configurable reviewer rejections

You can now decide which reject actions your reviewers have. Administrators choose which options appear (requeue to the same annotator, send to a different annotator, or remove from the queue) and set the default. Reviewers get a dedicated keyboard shortcut for each action.

A new **By Annotator** review ordering mode lets reviewers work through one annotator's submissions at a time before moving to the next, which makes it easier to judge a single person's work as a body.

For more information, see [the docs](TODO-LINK).

![Screenshot](/images/releases/2-37-reviewer-reject-actions.png)

#### Ask AI for annotators and reviewers

Annotators and reviewers can ask questions about their work without leaving the task. Answers draw on project and payment context, so questions about guidelines, task requirements, and pay are answered in one place. Attach a screenshot to a question when the answer depends on what is on screen.

Enable Ask AI per project.

![Screenshot](/images/releases/2-37-ask-ai-annotator.png)

!!! attention Availability
    Ask AI for annotators and reviewers ships behind a feature flag. Contact your HumanSignal account team to turn it on for your organization.

#### Manual payment batches and incentive campaigns

Two additions to payment programs:

- **Manual batches** let administrators issue one-off corrections to named workers directly from a program, without regenerating a pay run.
- **Incentive campaigns** pay increasing bonuses as a worker completes more volume inside a time window.

Worker pay-rate displays now show active incentive badges, rate multipliers, and payment policy conditions such as ground truth exclusion, with a breakdown of base pay against bonus.

For more information, see [the docs](TODO-LINK).

![Screenshot](/images/releases/2-37-incentive-campaigns.png)

#### Filter and segment the Members table

The Members table now supports reusable, persisted filters for role, seat type, tags, last active date, workspace and project membership, and self-reported skills. Two columns were added: Membership, and identity-verification status.

![Screenshot](/images/releases/2-37-members-filters.png)

#### A mobile-friendly workforce experience

Workforce Home, Profile and Account Settings, identity verification, tax and payment method, and Home are now responsive on mobile. The top navigation bar no longer enforces a fixed minimum width, so contributors working from a phone get a usable layout throughout.

![Screenshot](/images/releases/2-37-mobile-workforce-home.png)

#### Additional new features

- Annotator evaluation metric, threshold, and minimum sample settings moved out of the pause toggle into the main Annotator Evaluation settings, each with its own default.
- An element inspector in the Interfaces preview lets you point at a specific UI element when you ask the agent to change it.
- Courses gained search within completed courses, a single-page review mode, URL links to specific pages, an update banner when content changes, and a readable countdown after a failed quiz.
- Contributor Opt-In requirements support selecting multiple accepted answers.
- Workspace selection menus show color-coded folder icons, and your own avatar for your personal sandbox.
- Keyboard shortcuts can be overridden per project without changing your account-wide defaults.
- The list of projects linked to an interface scrolls infinitely, and you can bulk-assign a published interface version to several linked projects at once.
- Data Manager tasks can be filtered by **Reviewed at**, and filter and column options in the picker sort alphabetically.
- You can remove a contributor from a pay run without regenerating the whole run.

### Feature updates

#### A clearer Interfaces chat and builder

The Interfaces chat now streams responses and shows activity and tool indicators as the agent works. It also accepts voice input, presents plan approval cards before acting, and has a redesigned prompt bar. In the builder, every tab shows which published version you are viewing, Data I/O displays enum values for labels, and you can test Submit validation directly in preview.

For more information, see [Interfaces](interfaces).

![Screenshot](/images/releases/2-37-interfaces-chat.png)

#### Members: Performance

The Evaluation column and badges are now limited to annotator and reviewer roles. Wording moved to **Passing** and **Failing**, rejection rate is colored so that lower reads as better, and members who have left a project are flagged while their evaluation history is kept. **Select All** now prioritizes members who have performance data when more members match a filter than the display limit.

#### Additional feature updates

- The Data Manager Filters panel has clearer icons and spacing, and handles locked tabs correctly: you can inspect Columns and Filters on a locked tab in read-only mode.
- Pay run and payout tables default to risk-aware sorting and show a pending-changes count on the regenerate button.
- Database connection handling was improved to reduce load on busy instances.

### Security

- Permission checks on project and model creation are stricter. Outbound requests and storage connections are protected against server-side request forgery, file serving blocks path traversal for local and exported files, and HTML and SVG sanitization is hardened. Self-hosted deployments get safer defaults for organization creation and for debug error pages.
- Fixed an issue where a signed media link issued for one project could read uploaded files belonging to another project in the same organization.
- Fixed an issue where forged activity events could make imported review records eligible for worker payment.

- Fixed Payments Programs and pay run issues: truncated customer and program names, programs that could not be renamed, archived programs missing from filter results, incorrect role labels and project counts, direct URLs to out-of-organization programs not returning a 404, and a project picker that listed projects with payments disabled.
- Fixed Data Manager filter issues, including incorrect "is empty" results, case sensitivity mismatches between parent and child filters, annotator result scoping, and runtime errors on unsupported fields or malformed regular expressions.
- Fixed locking a Data Manager tab restoring agreement columns that had been hidden.
- Fixed a server error when exporting learners who had not started a course, and a course page header that overlapped content during search.
- Fixed removing a workspace member reporting an error even though the removal succeeded, which left the Members table stale until a manual refresh.
- Fixed inconsistent sizing of the Workspace dropdown and other selection fields depending on surrounding layout.
- Fixed the "Duplication failed" badge appearing on projects that duplicated successfully.
- Fixed DocLang document export omitting page images and skipping content from drafts, predictions, and task data.
- Fixed a timeout when deleting a large number of task reviews or bulk-assigning tasks in large projects.
- Fixed project task and review counts going out of sync after certain overlap, skip, or edit scenarios.
- Fixed Managers submitting annotations beyond the configured task overlap limit, and restored their ability to submit new annotations from Quick View.
- Fixed View-Only seat issues, including inaccessible navigation, members who could not be deactivated or displayed correctly, incorrect role display, profile picture and notification handling, and inconsistent provisioning between manual invites and SSO.
- Fixed a hamburger menu button that stood out too much when active, inconsistent font sizing on mobile, and other polish issues in the header, Workforce Home, and account pages.
