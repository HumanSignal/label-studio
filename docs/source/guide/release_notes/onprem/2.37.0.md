## Label Studio Enterprise 2.37.0

<div class="onprem-highlight">Added Data Collection projects, Flex and View-Only seats, configurable reviewer rejections, and mobile-friendly UI</div>

*Oct 09, 2026*

Helm Chart version: [2.0.11](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### Breaking changes

- Payment Programs are now the only way to generate and approve payments. Per-project payment batch generation and the standalone Payments > Projects list have been removed in favor of program-level pay runs.
- The project-level "Enable payments" toggle is now a true kill switch: turning it off stops payment for all work in that project until it is turned back on (completed work is not lost and is paid once payments are re-enabled).

### New features

- Added a new Data Collection project type for crowdsourced file submissions, including multi-file bundles per task, configurable validation rules (file type, size, duration, resolution, orientation), review and payment integration, and a mobile-friendly upload experience with in-card previews for images, video, and PDFs.
- Added Flex seats, a licensing/seat type that lets organizations assign working roles with claim-based capacity enforcement, provisioned through invites, SSO/SCIM, and managed from the Members page.
- Added View-Only seats, a restricted read-only seat type with limited navigation, a persistent status indicator, and an upgrade path to a full seat.
- You can now promote annotator evaluation metric, threshold, and minimum sample settings out of the pause toggle into the main Annotator Evaluation settings, with per-metric defaults.
- Added configurable reviewer reject actions: administrators can choose which reject options (requeue to the same annotator, send to a different annotator, or remove from the queue) reviewers can use, set a default action, and reviewers now get dedicated keyboard shortcuts per action.
- Added a "By Annotator" review ordering mode so reviewers work through one annotator's submissions at a time before rotating to another.
- Added Ask AI support for annotators and reviewers, including per-project enablement, project and payment context in answers, and the ability to attach a screenshot to a question.
- Added manual payment batches so administrators can issue one-off corrections to named workers directly from a payment program, and added incentive campaigns that pay increasing bonuses as workers complete more volume within a time window.
- Added reusable, persisted filtering for the Members table, including filters for role, seat type, tags, last active date, workspace/project membership, and self-reported skills, plus a Membership column and identity-verification status column.
- Added an element inspector in the Interfaces preview so you can point at a specific UI element when asking the agent to make a change.
- Added search within completed courses, a single-page course review mode, URL links to specific course pages, an update banner for learners when course content changes, and a human-readable countdown after failing a quiz.
- Added support for selecting multiple accepted answers when configuring Contributor Opt-In requirements.
- Added color-coded workspace folder icons (and your own avatar for your personal sandbox) to workspace selection menus across the product.
- Added per-project keyboard shortcut overrides, so hotkeys can be customized per project without changing your account-wide defaults.
- Made the Workforce Home, Profile/Account Settings, identity verification, tax and payment method, and regular Home pages mobile responsive, and removed the fixed minimum width from the top navigation bar.
- Added infinite scrolling for the list of projects linked to an interface, and the ability to bulk-assign a published interface version to multiple linked projects at once.
- Added the option to filter Data Manager tasks by "Reviewed at," and to sort filter/column options alphabetically in the Data Manager filter picker.
- Added the ability to remove a contributor from a pay run without regenerating the entire run.

### Feature updates

- Improved the Data Manager Filters panel with clearer icons, spacing, and locked-tab handling, including read-only inspection of Columns and Filters on locked tabs.
- Improved worker pay-rate displays to show active incentive badges, rate multipliers, and payment policy conditions (such as ground truth exclusion), with a clearer breakdown of base pay versus bonus amounts, and improved pay run and payout tables with risk-aware default sorting and a pending-changes count on the regenerate button.
- Improved the Interfaces chat experience with streaming responses, activity/tool indicators, voice input, plan approval cards, and a redesigned prompt bar; the builder now shows which published version is being viewed on every tab and displays enum values for labels in Data I/O, and you can test Submit validation directly in preview.
- Improved Members: Performance so the Evaluation column and badges are limited to annotator/reviewer roles, use "Passing"/"Failing" wording, color rejection rate so a lower rate is better, and flag members who are no longer part of the project while preserving their evaluation history.
- Improved Member Performance "Select All" to prioritize members who actually have performance data when more members match a filter than the display limit.
- Improved backend database connection handling to reduce load on busy instances.

### Security

- Fixed several security issues, including stricter permission checks on project and model creation, protections against server-side request forgery in outbound requests and storage connections, prevention of path traversal when serving local or exported files, hardened HTML/SVG sanitization, and safer default settings for organization creation and debug error pages in self-hosted deployments.
- Fixed an issue where a signed media link issued for one project could be used to read uploaded files belonging to other projects in the same organization.
- Fixed an issue where forged activity events could make imported review records eligible for worker payment.

### Bug fixes

- Fixed numerous issues in the custom Interfaces builder and preview, including regions disappearing or rendering incorrectly on video, audio, brush, and vector labeling interfaces; relation lines not drawing on tall or scrolled screens; stale or duplicated chat history; and interface save or validation failures after agent edits.
- Fixed several issues in the Review stream and Quick View for interface-based projects where annotation data could appear blank, stale, or incorrectly reviewed after a Fix and Accept action, an undo, or navigating between annotations, and where comments on draft annotations were not saved or did not appear until the task was reopened.
- Fixed multiple issues on the Payments Programs and pay run pages, including incorrect truncation of long customer and program names, inability to rename a program, archived programs not appearing when filtered, incorrect role labels, incorrect project counts, direct URLs to programs outside the user's organization not returning a 404 page, and the project picker including projects that have payments disabled.
- Fixed several Data Manager filter issues, including incorrect results for "is empty," case sensitivity mismatches between parent and child filters, annotators seeing results scoped to their own work only where intended, and runtime errors when filtering on unsupported fields or malformed regular expressions.
- Fixed an issue where locking a Data Manager tab restored previously hidden agreement columns.
- Fixed several course viewer issues, including a server error when exporting learners who had not started a course, and a page header overlapping content while searching within a long course.
- Fixed an issue where removing a workspace member reported an error even though the removal succeeded, leaving the Members table stale until a manual refresh.
- Fixed inconsistent sizing of the Workspace dropdown and other selection fields depending on their surrounding layout.
- Fixed the "Duplication failed" badge appearing incorrectly on successfully duplicated projects.
- Fixed an issue where DocLang document export did not include page images and did not pull content from drafts, predictions, or task data.
- Fixed a timeout when deleting a large number of task reviews or bulk-assigning tasks in large projects.
- Fixed an issue where project task and review counts could become out of sync after certain overlap, skip, or edit scenarios.
- Fixed an issue where Managers could submit annotations beyond the configured task overlap limit, while restoring the ability for Managers to submit new annotations from Quick View.
- Fixed numerous View-Only seat issues, including inaccessible or inconsistent navigation, inability to deactivate or correctly display View-Only members, incorrect role display, profile picture and notification handling, and inconsistent provisioning between manual invites and SSO.
- Fixed a hamburger menu button that stood out too much when active, inconsistent font sizing on mobile, and other small UI polish issues in the header, Workforce Home, and account pages.
