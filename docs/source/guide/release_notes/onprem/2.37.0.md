## Label Studio Enterprise 2.37.0

<div class="onprem-highlight">Added Interfaces, View-Only and Flex seats, Data Collection projects, and reworked Payments workflows</div>

*Oct 07, 2026*

Helm Chart version: [2.0.11](https://github.com/HumanSignal/charts/blob/master/heartex/label-studio/Chart.yaml)

### Breaking changes

- Payments are now generated and approved only at the Program level. Per-project payment batch generation/approval and the "Payment Batches" project settings tab have been removed; the "Enable payments" toggle on a project is now a single switch that determines whether the project can be paid at all, and projects outside a payment program can no longer be paid directly.

### New features

- Added Interfaces, an AI-assisted builder for custom labeling and review interfaces, including an agent that creates and edits interface code from natural-language prompts, a live preview with element selection, plan/approval workflow, voice input, version history, and the ability to apply a published version to one or more linked projects.
- Added View-Only organization members: these users get read-only access to Analytics and dashboards scoped to their assigned projects, see a persistent notice, and can request a full seat.
- Added Flex seats, a workforce seat type that lets annotators and reviewers rotate through a shared capacity pool instead of each requiring a dedicated license seat, with manual invite, SAML/SCIM provisioning, and an admin option to force-release an active claim.
- Added Data Collection projects, a project type in which contributors submit uploaded files (images, video, audio, PDFs) as their work. Supports configurable file type/size/duration/count validation, multiple files per task, mobile uploads, in-card previews (including paginated PDFs), review and payment of submissions, and a dedicated settings page for validation rules.
- You can now configure the annotator evaluation metric, score threshold, and minimum sample size directly in project quality settings, independent of the pause-on-failure toggle.
- Added Manual payment batches so administrators can pay named workers one-off amounts outside the normal pay-run flow, with safeguards against duplicate payments.
- Added campaign incentives: volume-based bonuses that pay workers once they complete a configured amount of work within a defined time window.
- You can now choose how reviewers reject work: remove it from the queue, return it to the same annotator, or redistribute it to a different annotator, each with its own keyboard shortcut and menu option.
- Added a review ordering mode that groups review work by annotator and rotates between annotators at a configurable coverage percentage.
- You can now customize keyboard shortcuts per project, in addition to your account-wide defaults.
- Extended Ask AI access to annotators and reviewers, including screenshot attachments and awareness of the task and project currently open.
- Added filtering to the Label Distribution chart in project dashboards, so counts can be narrowed by task data, annotator, model version, review outcome, or ground truth.
- Added richer filtering (role, user type, tags, last active date, workspace/project membership, skills) and persisted, customizable columns to organization member lists.
- Added Azure Storage authentication using workload identity (service principal), so a storage connection no longer requires a stored secret.
- Completed course learners now see a banner when a course page they finished has since been updated, with links to jump to the changed pages; course pages also support in-page search, a single-page review mode, and direct links to individual pages.
- Added License and Usage reporting for Flex seat entitlements.
- Added an identity-verification status column to the organization members list.

### Feature updates

- Improved the mobile responsive layout across the top navigation, Home page, Workforce Home, Account Settings, Skills & Expertise, Identity Verification, and Tax & Payment Method pages.
- The Workforce projects "Completed" column was renamed "Submitted" and no longer counts skipped tasks, so the number better reflects actual paid work.
- In Members: Performance, the Rejection Rate column now colors 0% as good, the Evaluation column only shows a status for Annotators and Reviewers, its badges read "Passing"/"Failing", and the view now flags when a listed annotator is no longer a project member. "Select All" now prefers members with performance data.
- Removed the "Common Questions" and Courses widgets from the Workforce Home page to keep the focus on available work.
- Improved DocLang document export: page images now download through the authenticated storage connection, multi-page documents are supported, and drafts or predictions can be used as the export source when no final annotation exists.
- Improved performance of Data Manager filtering, column loading, pay-run generation, and Label Distribution recalculation on large projects.
- The Interfaces overview page now supports more than 100 linked projects and lets you apply a published interface version to several linked projects at once.
- Improved the Data Manager Filters panel: clearer row separation, consistent icons, alphabetical ordering of filter/column options, read-only behavior when a tab is locked, and the ability to filter by review timestamp.
- Workforce pay-rate displays now show active incentive badges, bonus breakdowns, and policy conditions (such as "requires accepted review") next to the base rate; administrators can now remove a contributor from a pay run without regenerating the whole run.
- The Payments pay-run review screen now marks rows with deferred time overrides, shows the previous value, and reports how many rows will change on regeneration; payout tables sort by risk (missing data, idle, slow, low quality) by default.
- Course quizzes now show the remaining retry wait time in a human-readable format and can be configured to not highlight correct or failed questions; the "Max retries" setting was renamed "Max attempts".
- Various accessibility and visual polish: larger, keyboard-reachable close buttons on tags, consistent active-state styling for the navigation menu, and consistent sizing for selection controls.

### Security

- Fixed an issue where a sandboxed custom interface could read files uploaded to other projects in the same organization.
- Fixed an issue that allowed concurrent requests to create duplicate annotations from the same annotator.
- Fixed an issue where task creation could reference a project outside the caller's organization.
- Improved protection against server-side request forgery in storage connections and local file access, and hardened several backend endpoints against unauthorized access.
- Fixed an issue where SAML/SCIM provisioning could leave orphaned user accounts or fail once a license seat limit was reached.

### Bug fixes

- Fixed several issues on Payments pages: program status not updating automatically, links to programs outside your organization not returning a 404, archived programs not appearing when filtered, long customer/program names overflowing their columns, and inability to rename a program.
- Fixed an issue where the "Add Projects" button on the Program Overview page stayed disabled despite valid default selections, where roles were labeled "annotation"/"review" instead of "Annotator"/"Reviewer" after generating batches, and where the recipient ID was missing from exported payment batch CSV files when no payment provider was configured.
- Fixed several Data Manager filter issues: annotator and comment filters could return other users' annotations to a logged-in annotator; case sensitivity was inconsistent between parent and child comment filters; invalid regular expressions caused a server error instead of a validation message; confusing or unsupported operators (such as "Ground Truth is empty") were removed; Annotation ID child filters did not match correctly; dimension "is not" filters combined with child filters returned wrong results; and the "Filter on" dropdown differed between pinned and unpinned modes.
- Fixed an issue where locking a Data Manager tab could restore previously hidden columns, where some filter fields did not visually disable on a locked tab, where multi-selected Annotator filters were not truncated, where the Annotators column could appear blank for completed tasks after certain review actions, and where adding a column with unsupported characters could cause a server error when filtering on it.
- Fixed several review and labeling issues in custom interfaces: stale state showing a blank canvas after Fix + Accept, Accept/Reject labels not reflecting the actual review state, duplicate or "phantom" history entries, draft text being lost on browser refresh, comments on drafts not saving or displaying promptly, and the review stream not showing regions when switching between annotations on the same task.
- Fixed an issue where deleting predictions or large batches of reviews could time out.
- Fixed several issues in the interface creation/editing agent: the copy button on agent responses not copying content, the "Build custom grid view" option not taking effect after the first prompt, editing a previous prompt not fully replacing earlier context, the Plan toggle staying on after a plan was approved, multi-select clarifying questions rendering as single-select, validation errors from a duplicated interface failing to save, the agent not seeing its own code when iterating, and the agent ignoring requested label restrictions.
- Fixed several video and region rendering issues in Interfaces-based projects: frame navigation and frame counts, relation connector lines, brush/vector/rectangle regions not rendering or being selectable, duplicate delete controls in the Info panel, and regions not appearing until playback started.
- Fixed an issue where output data could be duplicated or inconsistent for interfaces that emit the same field under multiple names, and where renaming an output field could leave the interface broken.
- Fixed an issue where annotation agreement showed 100% even when spatial or named-entity annotations from custom interfaces were completely different, including for locally built interfaces.
- Fixed an issue where exporting course learner lists could return a server error on large courses, where the course search could scroll the wrong part of the page, and where clicking in the course viewer could leave elements looking incorrectly selected.
- Fixed an issue where strict task overlap could still be exceeded by managers and above, and where a skipped task could remain in "Initial" state after switching the skip-queue setting to "Ignore skipped".
- Fixed an issue where the "Assign same-level roles" permission did not restrict which roles a Manager could assign, including on on-premises deployments.
- Fixed an issue where removing a project member could return a server error and leave the Members table showing the removed user until a refresh.
- Fixed an issue where YOLO export with images failed to include images for projects using cloud source storage.
- Fixed numerous View-Only seat issues: access to pages that should be restricted (Hotkeys, Prompts, Data Manager filters, notifications), inability to update a profile picture or name, inability to be deactivated or assigned, missing or incorrect role/status badges, being misrepresented as an organization owner, SSO-provisioned View-Only users not being assigned a workspace, and permission errors when navigating between Analytics pages.
- Fixed an issue where the Update button could remain disabled after making changes and using Undo, and where an annotation could be updated via a hotkey despite the Update button being disabled.
- Fixed an issue where the Submitted vs. Accepted annotations chart did not show accepted annotations for Interface-based projects, and where Evaluation results for removed project members were not displayed.
- Fixed several review-counter mismatches on project cards and in the reviewer dashboard, including when "Reject and return to annotator" is used.
- Fixed an issue where a duplicate account activation email could be sent to an already-activated user, and where users with invalid email addresses could be created.
- Fixed several issues with interface version management: canceling the version-switch confirmation did not revert the selection, manually added labels could be overwritten when the linked interface was updated, breaking changes were not detected when publishing a new version, labels removed from a newer version remained selectable, unpublished interfaces appeared in the "Saved Interfaces" picker, and the Interfaces list did not refresh after deleting an interface.
- Fixed miscellaneous interface editor issues: redundant scrollbars in the Outliner panel, the delete-region button appearing enabled on read-only history entries, annotators being unable to use the resolve/unresolve comment action on other users' comments, Select Element mode staying active after submitting a prompt, and style changes to custom interfaces sometimes being served from a stale cache.
- Fixed an issue where locally built interfaces could lose Undo/Redo/Reset actions, fail to load local data on the first attempt in the playground, not respect single-choice selection in default templates, or fail audio date/time region submission; also fixed slow or unresponsive audio waveform rendering after interface generation.
- Fixed an issue where the Members dashboard returned a server error when annotation authors had been deleted, and where SSO group-to-project mapping could be applied only partially despite a warning that it would not be applied.
