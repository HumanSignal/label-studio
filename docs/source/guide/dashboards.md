## Project dashboards

Project dashboards are available from a project's **Dashboard** tab. They focus on one project at a time.

| Dashboard | Description |
|-----------|-------------|
| [**Project dashboard**](dashboard_project) | Overview of the project Dashboard tab and links to project-level dashboards. |
| [**Throughput dashboard**](dashboard_throughput) | Track velocity, remaining work, completed tasks, and time spent annotating and reviewing. |
| [**Data quality dashboard**](dashboard_data_quality) | Analyze task agreement, agreement by dimension, confusion pairs, and confusion matrices. |
| [**Members dashboard**](dashboard_members) | Compare annotator, reviewer, and model performance within a project. |

Project dashboards are available to Managers, Administrators, and Owners.

## Analytics dashboards

Analytics dashboards are available from the main **Analytics** navigation and can include data across projects, workspaces, or individual members depending on your role.

| Dashboard | Description |
|-----------|-------------|
| [**Projects overview dashboard**](dashboard_overview) | Monitor progress across multiple projects and workspaces. |
| [**Label Distribution dashboard**](dashboard_distribution) | Compare annotation and prediction value distributions for project dimensions. |
| [**Member Performance dashboard**](dashboard_annotator) | Review an individual member's annotation and review activity across projects. |
